# 株ノート

自分専用の株式投資管理サイト。サーバー不要で、`index.html` をブラウザで開くだけで使えます。

## 機能

- **ダッシュボード**: 評価額・取得額・含み損益・実現損益・受取配当・トータル損益、保有銘柄一覧と構成比
- **売買履歴**: 買い／売りの記録・編集・削除、銘柄での絞り込み、売りごとの実現損益表示
- **配当**: 受取配当（税引後）の記録
- **年別損益**: 年ごとの実現損益と配当の集計（確定申告の確認用）
- **データ**: JSON でのバックアップ／復元、売買履歴の CSV 出力（Excel 対応）

## 計算方法

- 平均取得単価は**移動平均法**（買い手数料を取得額に含める）
- 実現損益 = 売却額 − 売り手数料 − 平均取得単価 × 売却株数
- 現在値は保有銘柄一覧で手入力します（未入力の銘柄は取得額で評価）

## データについて

データはブラウザの localStorage に保存され、外部には送信されません。
ブラウザのデータ削除や別のブラウザ・PC では見えなくなるので、「データ」タブから定期的に JSON をエクスポートしてください。
